# Penciled

A mobile app that reads your new screenshots and offers a one-tap action, starting with calendar events and deadline alerts. The model proposes; deterministic code validates; you confirm.

Status: design complete, build not started. Start with `STATUS.md`, `CLAUDE.md` and `docs/SESSION_START.md`. Design documents are in `docs/` (features, UI, technical design, build handoff, sprint plan).
